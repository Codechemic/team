# 비기능 요구사항 점검 결과

측정일: 2026-11-11 · 대상: 배포 빌드 (`npm run build`)

## UC-N01 성능 — 재료 입력 후 추천 결과 3초 이내
| 항목 | 조건 | 결과 |
|---|---|---|
| 추천 함수 `recommend_recipes` | PostgreSQL 16, 레시피 10,013개 · 레시피-재료 연결 74,794개, 재료 5개 입력 | 약 **36 ms** (3회 평균) |
| 추천 함수 | 같은 데이터, 재료 10개 입력 · 조리시간순 | 약 37 ms |
| 재료 검색 `search_ingredients('파')` | 같은 데이터 | 약 2.5 ms |
| 추천 버튼 → 결과 화면 | Galaxy A55 화면, CPU 1/4 감속, 느린 4G (체험 모드) | 330~440 ms |
| 첫 화면 표시 | 같은 조건 | 약 0.8초 |

- 첫 로딩을 줄이려고 홈·검색·추천·상세 화면만 먼저 받고, 나머지 화면(등록·조리·마이·관리자 등)은 열 때 받도록 나눔.
- React·Supabase 라이브러리를 따로 묶어, 새 버전을 배포해도 브라우저 캐시를 다시 씀.
- 실제 서비스에서는 위 시간에 Supabase(서울 리전)까지의 네트워크 왕복 시간이 더해짐.

## UC-N04 호환성 — Android 모바일
Playwright로 안드로이드 크롬 환경을 흉내 내 15개 화면을 모두 열어 봄.

| 기기 | 화면 크기 | 가로 넘침 | 스크립트 오류 |
|---|---|---|---|
| Galaxy S24 | 360×780 | 없음 | 없음 |
| Galaxy A55 | 480×1040 | 없음 | 없음 |
| Pixel 7 | 412×839 | 없음 | 없음 |
| Galaxy Z Flip 7 | 360×764 | 없음 | 없음 |
| Galaxy Z Fold 7 커버 화면 | 360×764 | 없음 | 없음 |
| Galaxy S III (작은 화면) | 360×640 | 없음 | 없음 |

안드로이드 대응:
- 휴대폰 **뒤로 가기 버튼**으로 열린 창(신고·삭제 확인, 사진 확대, 재료 수정 등)이 닫힘.
- 홈 화면에 추가할 때 쓰는 아이콘(maskable) 추가.
- 한글이 단어 중간에서 줄바뀜하지 않게 처리.
- 조리 모드에서 화면 꺼짐 방지(Wake Lock)와 타이머 진동은 안드로이드 크롬에서 지원.

## UC-N05 확장성
- 추천 계산은 DB 함수 한 번으로 처리하고, `recipe_ingredient(ingredient_id)` 인덱스로 재료가 들어간 레시피만 찾음.
- 레시피 1만 개에서도 40 ms 안쪽 (위 표).

## UC-N06 가용성 — 점검 사전 공지
- `frontend/public/notice.json` 의 `active` 를 `true` 로 바꾸고 `message`, `until`(공지 종료 시각)을 적어 GitHub에 저장하면, 자동 배포 후 모든 사용자 화면 위쪽에 공지 배너가 뜸. `until` 이 지나면 자동으로 사라짐.
- 인터넷 연결이 끊기면 "인터넷 연결이 끊겼어요" 안내 배너 표시.
- 화면 오류가 나도 흰 화면 대신 안내와 새로고침 버튼 표시 (새 버전 배포 직후 옛 화면 파일을 못 찾는 경우도 안내).
- 서비스 호스팅: Cloudflare Pages(정적 파일, 24시간), Supabase(DB·로그인).
